### TC-1: Успешное создание нового клиента

- **Приоритет:** High
- **Название:** Успешное создание клиента с валидными, динамически сгенерированными данными.
- **Предусловия:**
  1. Открыта страница менеджера по ссылке объекта тестирования.

- **Шаги выполнения:**
  1. Нажать на кнопку `Add Customer`.
  2. Сгенерировать тестовые данные: 10-значный `Post Code` и `First Name` по алгоритму из задания. `Last Name` = "Testov".
  3. Ввести сгенерированный `First Name` в поле "First Name".
  4. Ввести `Last Name` "Testov" в поле "Last Name".
  5. Ввести сгенерированный `Post Code` в поле "Post Code".
  6. Нажать на кнопку `Add Customer` под формой.

- **Ожидаемый результат:**
  - Появляется системное окно (alert) с текстом, содержащим "Customer added successfully".
  - После принятия alert, пользователь остается на странице `Add Customer`.
  - При переходе на вкладку `Customers` и поиске по сгенерированному `First Name`, в таблице отображается ровно одна строка.
  - Значения в ячейках этой строки (`First Name`, `Last Name`, `Post Code`) полностью соответствуют сгенерированным данным.

### TC-2: Сортировка клиентов по имени

- **Приоритет:** High
- **Название:** Проверка корректности сортировки таблицы клиентов по имени (First Name) в прямом и обратном порядке.
- **Предусловия:**
  1. Открыта страница менеджера.
  2. В системе существует как минимум 3 клиента с разными именами.

- **Шаги выполнения:**
  1. Перейти на вкладку `Customers`.
  2. Получить список имен из столбца "First Name" в их текущем порядке.
  3. Нажать на заголовок столбца `First Name` для активации сортировки.
  4. Получить новый, отсортированный список имен из таблицы.
  5. Нажать на заголовок столбца `First Name` еще раз.
  6. Получить новый, отсортированный в обратном порядке, список имен из таблицы.

- **Ожидаемый результат:**
  - После шага 4 список имен в таблице соответствует оригинальному списку, отсортированному в алфавитном порядке (A-Z).
  - После шага 6 список имен в таблице соответствует оригинальному списку, отсортированному в обратном алфавитном порядке (Z-A).

### TC-3: Удаление клиента по заданному условию

- **Приоритет:** High
- **Название:** Удаление клиента, имя которого имеет длину, ближайшую к средней арифметической длине всех имен.
- **Предусловия:**
  1. Открыта страница менеджера.
  2. В системе существует как минимум 3 клиента.

- **Шаги выполнения:**
  1. Перейти на вкладку `Customers`.
  2. Получить список всех имен клиентов из таблицы.
  3. Вычислить имя клиента для удаления согласно алгоритму из задания.
  4. В таблице найти строку, соответствующую вычисленному имени.
  5. В этой строке нажать на кнопку `Delete`.
  6. Обновить страницу или выполнить поиск по удаленному имени.

- **Ожидаемый результат:**
  - Строка с данными удаленного клиента пропадает из таблицы.
  - При поиске по имени удаленного клиента результат не находится (таблица пуста).
