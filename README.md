# Проект по автоматизации UI-тестов (Практикум SimbirSoft SDET)

Этот проект — мое решение практического задания по UI-автоматизации. В нем реализованы 3 автотеста для веб-приложения "Banking Project", покрывающие основной функционал.

---

### 🛠️ Стек технологий

*   **Python 3.10** — язык программирования.
*   **Pytest** — фреймворк для запуска тестов.
*   **Selenium** — библиотека для управления браузером.
*   **WebDriver Manager** — для автоматического управления версиями ChromeDriver.
*   **Allure Pytest** — для генерации отчетов.
*   **Black** — для форматирования кода.

---

### 🚀 Как запустить проект

#### Что нужно для запуска:
- Установленный Python (версии 3.10+)
- Установленный Git
- Установленный Allure Commandline (для просмотра отчетов)

#### Шаги для запуска:

1.  **Клонируйте репозиторий:**
    ```shell
    git clone <ссылка_на_твой_репозиторий>
    cd sdet_practicum_ui
    ```

2.  **(Рекомендуется) Создайте и активируйте виртуальное окружение:**
    ```shell
    py -m venv venv
    .\venv\Scripts\activate
    ```

3.  **Установите зависимости:**
    ```shell
    py -m pip install -r requirements.txt
    ```

4.  **Запустите тесты:**
    ```shell
    py -m pytest
    ```
    *Результаты для отчета будут сохранены в папку `allure-results`.*

5.  **Откройте отчет Allure:**
    ```shell
    allure serve allure-results
    ```
